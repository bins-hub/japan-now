- 304페이지의 page-level 구조화 데이터 제목·설명·URL·언어를 해당 HTML 메타데이터와 일치화했다. 4언어의 페이지 역할(목록/일반 페이지/안내 기사)을 맞추고 누락된 페이지 엔티티를 보완. FAQ·장소·식당 목록 엔티티를 삭제하지 않았다. OG 제목·설명 누락도 보완. 한국어 삿포로 겨울 제목의 ‘여행 여행’ 중복 정리.
- 실제 HTML 수정은 252페이지. 본문은 전부 원본과 바이트 단위 동일하며 URL·canonical·hreflang·이미지·링크·검색·플레이어를 유지한다. 새 페이지 없음, 색인 URL 304개 유지. 변경 URL의 sitemap 수정일만 2026-10-29로 맞췄다.
- 재적용 도구 `tools/align_search_metadata.py`, 안정적인 목적지/노선명·기존 설명은 `content/search-page-names.json`에 저장. 2차 실행 변경 0개 확인. 콘텐츠를 재생성한 뒤 이 도구를 실행하고 메타데이터 인벤토리도 함께 갱신한다. 새 목적지·노선은 명칭과 검색 의도를 먼저 검토한다.
- 신규 자동검사 `tools/check_search_metadata_parity.py`: 76묶음의 4언어 대응, 같은 언어 안의 고유 제목, HTML/OG/schema 제목·설명과 page URL·언어·역할 일치 검증. CI에 연결. 기존 FAQ 검사 포함 총 14개 검사를 실행한다.
