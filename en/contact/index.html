Contact JAPAN NOW

How to report a broken camera link, request a correction or send a site improvement suggestion.

Report a camera problem

Use the public JAPAN NOW GitHub issue tracker to report site errors. Include the camera page URL, city and error observed. A private contact email will be published after the operator confirms the address.

Suggest a correction

Please supply the relevant source link if information on a restaurant, attraction or route is inaccurate or outdated.

Privacy reminder

GitHub issues are public by default. Do not include passwords, addresses, phone numbers or other sensitive information.
