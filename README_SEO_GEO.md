# JAPAN NOW — AI 검색(GEO) + 일반 검색(SEO) 사이트 패키지

기존 JAPAN NOW 라이브 카메라 기능을 보존하면서 검색엔진에 별도 URL로 노출될 수 있는 정적 HTML 페이지를 추가했습니다. 공개된 실제 URL이 아직 없으므로 가짜 canonical이나 가짜 sitemap.xml을 넣지 않았습니다.

## 포함 페이지 (24개)

- `index.html` : 메인 라이브 카메라 11개 + 도시 및 카메라별 링크 + 사용자 질문에 대한 직접 답변
- `cameras/*/index.html` : 각 영상과 일본 관광지 안내를 결합한 카메라 11개 페이지
- `regions/*/index.html` : 도쿄·오사카·교토·후지산·홋카이도·규슈/오키나와 지역 6개 페이지
- `guides/*/index.html` : 무료 시청, 여행 활용, 재생 오류 관련 가이드 3개
- `about/`, `privacy/`, `contact/` : 운영 소개 및 안내 페이지 3개

## 배포 순서

1. ZIP 압축을 해제한 뒤 **폴더 내용물 전체**를 GitHub Pages나 정적 웹 호스팅에 올립니다. 최상위 폴더가 웹사이트 루트입니다.
2. 공개 HTTPS 사이트 주소가 정해지면, 압축을 푼 폴더에서 다음 명령을 실행합니다. **실제 주소만** 입력하세요.

   ```bash
   python3 tools/configure_domain.py https://your-real-domain.com
   ```

   GitHub Pages 하위 경로라면 경로도 포함하세요.

   ```bash
   python3 tools/configure_domain.py https://YOUR_GITHUB_ID.github.io/japan-now
   ```

3. 명령 실행 후 변경된 파일 전체를 다시 업로드합니다. 명령이 각 페이지의 `canonical`과 `og:url`, 구조화 데이터의 공개 URL 및 `sitemap.xml`, `robots.txt`를 설정합니다.
4. Search Console에 공개 사이트 등록 → 실제 URL의 `sitemap.xml` 제출 → 대표 페이지의 URL 검사로 색인 상태 확인.
5. 네이버 서치어드바이저와 Bing Webmaster Tools에도 등록하고 색인을 확인합니다.

## AI 검색 최적화 내용

- 각 도시와 장소를 고유한 HTML URL로 제공 (JS가 없는 크롤러도 텍스트 읽기 가능)
- 질문-답변 형태의 사용자에게 유용한 텍스트 및 출처와 주의사항 표시
- `WebSite`, `WebPage`, `CollectionPage`, `Article` 및 목록 정보를 페이지 내용에 맞게 JSON-LD로 설명
- HTML에서 직접 클릭 가능한 상호 연결 링크 (내부 URL 436개 정적 검사)
- `robots.txt`에 `OAI-SearchBot`, Googlebot, Bingbot 허용 규칙 설정

구글의 AI 개요/AI 모드에 특별한 'AI 전용 파일'이 필요한 것은 아닙니다. 중요 부분은 크롤링 허용, 잘 읽히는 텍스트와 유용하고 정확한 페이지입니다. ChatGPT 검색에 노출되려면 OAI-SearchBot이 사이트에 접근 가능해야 합니다. 어느 검색 서비스에서도 추천이나 상위 노출을 **보장하지 않습니다.**

## 실서비스 공개 전 반드시 해결할 일

1. **방송 원본 검증**: 영상 링크 및 방송사가 여전히 활성인지, 외부 임베드와 상업 이용을 허용하는지 확인하고 허가가 필요하면 확보합니다. 출처 페이지가 열린다고 현재 LIVE란 뜻은 아닙니다.
2. **운영자 정보**: `contact/`, `privacy/`는 초안입니다. 운영 주체, 실제 연락 가능한 이메일/문의 양식, 사업 정보(해당 시), 이용 중인 광고·분석 도구와 쿠키 정책을 사실대로 기재해야 합니다. 초안 상태로 애드센스 신청하지 마세요.
3. **독창적인 내용**: 카메라 링크만으로는 콘텐츠의 독창성이 약할 수 있습니다. 현지 장소별 독립 여행 정보, 동선, 참고 링크 등 실제 사용자에게 도움이 되는 검증된 원고를 보강하세요.
4. **방송 재생**: 공개 HTTPS 도메인에서 모바일/PC 영상 재생을 별도 검사해야 합니다. 방송 종료·지역 제한·외부 재생 제한은 코드로 해결할 수 없습니다.
5. **실제 robots 제어**: GitHub Pages **프로젝트 하위 경로**의 `robots.txt`는 호스트의 최상위 robots 파일을 대체하지 않습니다. 크롤러 차단 여부는 실제 사이트의 **origin root** `https://도메인/robots.txt`를 확인하세요.
6. **추적**: Search Console 검색어/색인/클릭과 실제 AI 출처 링크 유입을 확인하고, 원고 및 사이트 상태를 지속 개선하세요.

## 사전 점검
- 정적 HTML 24개, 서로 다른 title 24개, JSON-LD 문법 오류 없음
- 상대 내부 링크 436개 점검 통과
- 390px·1440px 폭에서 홈 및 대표 카메라 페이지의 가로 넘침 없음
- 홈 카메라 목록 11개, 지역별 필터 선택 정상 작동
- 실제 AI 인용 여부/검색 색인 여부, 유튜브 외부 재생 가능 여부는 공개 배포 이후 확인 필요
